# Public development distribution implementation — 2026-11-01

## Authorized and implemented

The owner requested implementation of the approved website, public Android provider connection and automated distribution plan, including the supplied detailed marketing prompt. Source is on `codex/public-development-distribution`; unrelated review-recovery edits were preserved.

The website contains the full single-page product story, original supplied logo, bundled Figtree/OFL notice, labelled illustrative interface, accessible navigation, Lenis/GSAP, runtime reduced-motion handling, Back to Top, privacy/requirements and honest download states. GitHub Pages hosts only static output; release metadata is embedded at build time and checked before a download link appears. No browser demo, account, analytics or live provider request is present.

The gateway has a separate FastAPI entry point with no catalog/database dependency. It uses fixed Gemini contracts exported from the current Dart builders, allowlisted REST operations, server credentials, App Check identity verification, bounded payload/output and safe failures. Shared nonpersonal Firestore reservations have no automatic funding/refill. Public Android transport preserves native journal bodies/identities, legacy saved lookups and explicit retries. Private debug access remains supported, while public builds reject private provider defines and require separate release signing.

GitHub workflows run website, API, Flutter and guarded native checks. Passing `main` pushes may publish immutable signed APKs and update the website only after the disabled-by-default flags and qualification record are enabled. Cloud Run deployment is separately manual and gated. [Distribution setup](../DISTRIBUTION.md) owns exact configuration and costs.
