Arrival does not complete tasks, and only saved Done advances guidance.

Matching displayed places reuse their component/result; actual additional presentation loads are separately accounted through the existing quota ledger. Backgrounding/disposal still stops guidance; no hidden coordinate scraper, name search, branch substitution, planning change, new gateway route or background tracking is added. Ordinary releases retain their disabled defaults. Test builds enable the new flag only with the existing public-test/alternative-navigation settings.
