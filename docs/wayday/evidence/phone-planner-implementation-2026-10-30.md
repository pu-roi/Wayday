## Gemini connection and paid-tier gate

The selected model is `gemini-3.1-flash-lite`, returned by a read-only model-list request using the supplied credential. The Android bridge calls a fixed HTTPS endpoint and never returns the key to Dart. The ignored key remains outside Flutter defines and manifest resources. One-time private debug provisioning streams it through ADB standard input into app-private storage, encrypts it with an Android Keystore key in no-backup storage, and removes the import file. USB/laptop access is not a runtime requirement after setup. This is a private presentation arrangement, not production client secrecy. Release builds refuse this credential path; Firebase AI Logic or another managed boundary remains separate qualification.

The owner confirmed **Paid tier**, approximately $4 credit remaining, and authorized proceeding with conservative request limits. Default provisioning is zero until an allowance is supplied. The authorized presentation allocation is **ten attempts total**, split into one isolated live qualification and nine phone attempts. Native enforcement and durable Dart accounting both limit attempts to three per rolling day; failed dispatched attempts consume allowance. The adapter reuses a successful unchanged interpretation in memory, coalesces identical requests in flight, and never automatically retries. Changed place/route choices do not require another interpretation. A title/note change requires deliberate re-interpretation before discovery.

The fixed native endpoint accepts only a bounded 50,000-byte text/schema request, one candidate and at most 4,096 output tokens, with no tools or cached-content attachment. At the reviewed model prices, reserving approximately $0.025 per attempt provides a conservative planning estimate of $0.25 for ten attempts. This is not an account-wide financial guarantee: other projects, service usage, pricing changes, reinstall or explicit reprovisioning remain outside the counter. Do not refill an exhausted allowance automatically.

Published Standard text pricing reviewed on this date is $0.25 per million input tokens and $1.50 per million output/thinking tokens. The adapter bounds input text and output length and does not use paid grounding. Actual cost depends on token usage and the project's billing terms. [Google's model pricing](https://ai.google.dev/gemini-api/docs/pricing#gemini-3.1-flash-lite).
