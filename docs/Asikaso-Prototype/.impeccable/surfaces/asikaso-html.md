Scope: Asikaso clickable prototype (asikaso.html), all app screens at phone viewport. Mode: Operate.

Audience/job: anyone with a day of errands; type errands as notes, get a fitted plan, run it.
Constraints: no Commute mode; From/To chosen on a map; errands typed in a single notepad with structured controls tucked under collapsible Advanced settings; notes-first errand input with AI interpretation, picker second; recurring list; branch picker; Go hands off to maps.
User steer (round 2 re-roll): simple, little color, inspired by established apps (Life360, Google Maps, Waze, Notion). Taken as the standing exit: the category standard at full craft.

## Direction contract

THESIS: The category standard done at full craft: Notion's calm note surface for input, Life360/Maps' map-plus-sheet for the plan. Refuses decorative worlds and color-coded busyness.

OWN-WORLD: White ground, warm-gray surfaces (#F6F6F4), ink #191919, hairlines #E7E7E4. One accent blue (#2F5CFF) for route, selection and links only; black primary buttons. State colors only where meaningful: green fits, amber tight, red didn't fit. Figtree (workhorse UI sans), tabular numerals, 12px radius sheets, soft offset shadows on floating layers only. Drawn line icons (one stroke).

STORY: The user writes their day like a note, sees Asikaso turn each line into a chip-tagged errand, taps Plan, reads one sentence ("Kasya lahat. Home 5:30") and a map, swaps a branch if they like, then goes leg by leg.

FIRST VIEWPORT: Today screen: title and date; one route card reading top to bottom: From (tap to choose on a map), a collapsible Errands section (Write/Pick toggle; a notepad where errands are typed one per line; Asikaso's read-out of each line as chips; a collapsed Advanced settings holding the per-errand structured controls), To (tap to choose on a map), then Leave / Home by / Travel. Black "Plan my day" pinned above the tab bar; settings live in the tab bar (user-directed layout, 2026-10-13).

FORM: Category standard (canon), executed straight; reached as the standing exit after two direction rolls (Kalendaryo, then Sari-sari Sign) were re-rolled by the user with a steer toward Life360/Maps/Waze/Notion. This CLI version printed no SEED REFERENCE, so none is recorded.
