# Wayday Team Planning & Task Board

This document is for the team to plan, organize, and track tasks.

> [!TIP]
> **Automated Updates with Agent Skill**:
> Once you add tasks with a Task ID (e.g. `TASK-01` or `M1-01`), any team member or AI agent can update task status and automatically log contributor progress using the `wayday-task-tracker` skill, or by running:
> ```powershell
> # Mark a task as in progress (automatically detects your Git username and GitHub handle)
> py .agents/skills/wayday-task-tracker/scripts/track_task.py start <TASK-ID>
>
> # Mark a task as done (records your Git name, email, GitHub handle, timestamp, and notes in PROGRESS.md)
> py .agents/skills/wayday-task-tracker/scripts/track_task.py done <TASK-ID> --notes "Summary of changes"
> ```
> See [PROGRESS.md](PROGRESS.md) for the activity log and contributor audit trail.
